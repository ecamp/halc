# halc

The **HAL client** that does the heavy lifting for talking to your HAL (or other linked data) API. 💪🏽🟢

Successor of [hal-json-vuex](https://github.com/ecamp/hal-json-vuex) and
[hal-json-normalizer](https://github.com/carlobeltrame/hal-json-normalizer), see
[ecamp/ecamp3#11062](https://github.com/ecamp/ecamp3/issues/11062).
